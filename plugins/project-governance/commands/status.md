# Governance status

Invoke the `project-governance` skill and follow "Status" in its
`references/maintain.md`. This is read-only: report established versus proposed
policy, missing or broken references, unresolved ownership, reviewer availability,
and drift between documented conventions and repository evidence. If governance
has not been initialized, say so and suggest `/project-governance:init`.
